# 道教基础知识

## 一、道教的起源

道教是中国本土产生的宗教，形成于东汉时期（公元25-220年），其思想渊源可追溯至先秦时期的道家哲学。

### 主要思想渊源

- **道家哲学**：以老子、庄子为代表的先秦道家思想，是道教最核心的理论来源。
- **神仙方术**：战国以来流行的神仙传说与追求长生不老的方术实践。
- **黄老之学**：汉初盛行的黄老道家，将黄帝与老子并尊。
- **民间信仰**：古代的自然崇拜、鬼神信仰和巫术传统。

## 二、道教的核心教义

### 1. 道

"道"是道教最高信仰，是宇宙万物的本源和运行法则。《道德经》开篇即言：

> 道可道，非常道；名可名，非常名。

道无形无象，超越一切具体事物，却又内在于万物之中。

### 2. 德

"德"是道在万物中的具体体现，是道的作用和功能。修道即修德，德行圆满方可合道。

### 3. 自然无为

- **自然**：万物依其本性自然发展，不假外力。
- **无为**：非不为，而是不妄为、不强为，顺应自然规律而行。

### 4. 清静寡欲

追求内心的清静安宁，减少对外在物欲的追逐，回归本真。

### 5. 长生久视

道教追求身心健康、延年益寿，最终目标是通过修炼达到与道合一、长生不老的境界。

## 三、道教的发展历程

| 时期 | 重要事件 |
|------|----------|
| 东汉 | 张道陵创立五斗米道（天师道），太平道出现 |
| 魏晋 | 葛洪著《抱朴子》，上清派（茅山宗）兴起 |
| 南北朝 | 寇谦之、陆修静改革天师道，道教制度规范化 |
| 唐代 | 皇室尊老子为始祖，道教为国教，全盛时期 |
| 宋代 | 真宗、徽宗崇道，道教继续发展 |
| 金元 | 王重阳创全真道，道教形成正一、全真两大派 |
| 明清 | 道教趋于衰落，民间化发展 |

## 四、道教的基本术语

- **三清**：道教最高神，即玉清元始天尊、上清灵宝天尊、太清道德天尊
- **三宝**：道、经、师（或道宝、经宝、师宝）
- **太极**：宇宙从无极到万物的过渡状态
- **阴阳**：宇宙中相对相成的两种基本力量
- **五行**：金、木、水、火、土五种基本元素
- **八卦**：乾、坤、震、巽、坎、离、艮、兑
- **丹道**：内丹修炼的理论与方法体系
- **符箓**：道教法术中的符书与秘文
