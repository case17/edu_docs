# 道教神仙体系

## 一、道教神仙观

道教的神仙体系庞大而复杂，大致可以分为以下几个层次：

1. **先天尊神**：与道同体，宇宙本源之神
2. **仙真**：修道成仙者
3. **神明**：执掌天地事务的神
4. **民俗神灵**：民间信仰中融入道教的神

> 道教认为，神与仙有别：神多为天地自然之职司，仙多为修道成就之果位。

## 二、先天尊神——三清

三清是道教最高神，代表道的三个层面：

| 尊神 | 全称 | 所居 | 象征 |
|------|------|------|------|
| 元始天尊 | 玉清圣境元始天尊 | 玉清境 | 宇宙创生之始 |
| 灵宝天尊 | 上清真境灵宝天尊 | 上清境 | 宇宙运行之道 |
| 道德天尊 | 太清仙境道德天尊 | 太清境 | 道德教化之尊 |

> 道德天尊即太上老君，为老子之神格化。

## 三、四御

四御是辅佐三清、执掌天地的四位大帝：

1. **昊天金阙玉皇大帝**——总执天道，万神之主
2. **中天紫微北极大帝**——执掌天经地纬、日月星辰
3. **勾陈上宫天皇大帝**——执掌天地人三才，统御星斗
4. **承天效法后土皇地祇**——执掌阴阳生育、大地山河

> 玉皇大帝在民间影响最大，常被误认为道教最高神，实际地位在三清之下。

## 五、重要仙真

### 1. 八仙

道教最广为人知的仙真群体：

| 仙真 | 原型 | 法器 |
|------|------|------|
| 铁拐李 | 乞丐形象 | 铁拐、葫芦 |
| 汉钟离 | 汉代将军 | 芭蕉扇 |
| 吕洞宾 | 唐代书生 | 纯阳剑 |
| 张果老 | 唐代方士 | 纸驴、鱼鼓 |
| 何仙姑 | 女性仙真 | 荷花 |
| 蓝采和 | 优伶形象 | 花篮 |
| 韩湘子 | 唐代文士 | 笛子 |
| 曹国舅 | 皇亲国戚 | 拍板 |

> 八仙代表"男女老少富贵贫贱"各色人等，寓意人人皆可修道成仙。

### 2. 其他重要仙真

- **西王母**：女仙之首，掌管昆仑仙界
- **东华帝君**：男仙之首
- **张道陵**：天师道创始人，正一天师
- **葛玄**：太极仙翁，葛洪从祖
- **许逊**：净明道祖师，许真君
- **萨守坚**：萨真人，西河派祖师
- **三茅真君**：茅盈、茅固、茅衷，茅山道祖师

## 六、自然与职司之神

- **三官大帝**：天官（赐福）、地官（赦罪）、水官（解厄）
- **雷声普化天尊**：九天应元雷声普化天尊，主雷
- **东岳大帝**：泰山之神，主幽冥
- **酆都大帝**：北方酆都，主鬼
- **灶君**：司命灶神，监察人间善恶
- **城隍**：守护城池之神
- **土地**：地方保护神
- **财神**：赵公明（正财神）、关公（武财神）、比干（文财神）

## 七、星辰之神

- **斗姆元君**：众星之母
- **南斗六星君**：主生（延寿）
- **北斗七星君**：主死（解厄）
- **太岁星君**：值年太岁，六十甲子各有一位

## 八、民俗道神

道教在发展中吸收了大量民间神灵：

- **关圣帝君**：关羽，忠义之神
- **妈祖**：林默娘，航海保护神
- **碧霞元君**：泰山老奶奶，送子护幼
- **文昌帝君**：掌管功名禄位
- **真武大帝**：北方之神，镇守玄武
- **药王**：孙思邈，医药之神
- **龙王**：掌管降雨水泽

## 九、神仙品位

道教将仙分为若干等级，不同经典说法不一，以《钟吕传道集》为例：

| 品位 | 特征 |
|------|------|
| 鬼仙 | 阴灵不散，不离鬼趣 |
| 人仙 | 延年益寿，不离人趣 |
| 地仙 | 长生住世，不离地趣 |
| 神仙 | 超脱无碍，不离神趣 |
| 天仙 | 阳神冲举，升入天界 |

> 最高目标为天仙，其次神仙，地仙可长住人间，人仙仅延寿而已。
