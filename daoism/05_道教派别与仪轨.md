# 道教派别与仪轨

## 一、道教主要派别

道教在历史发展中形成了众多派别，目前影响最大的两大派系为**正一道**和**全真道**。

### 1. 正一道

- **起源**：源于张道陵创立的五斗米道（天师道）
- **正式形成**：元成宗大德八年（1304年）封张与材为正一教主
- **特点**：
  - 以符箓斋醮为主要活动
  - 道士可以结婚生子（称"火居道士"）
  - 不必全住宫观，可居家修行
  - 重视度人济世

**正一道主要支派**：
- 龙虎山天师道
- 茅山上清派
- 阁皂山灵宝派
- 净明道
- 武当山派（早期属正一）

### 2. 全真道

- **创立**：金代王重阳（1112-1170）
- **特点**：
  - 强调内丹修炼与心性修养
  - 道士必须出家住观，不婚不荤
  - 重视清修苦行
  - 三教合一（融摄儒释道）

**全真道主要支派**（七真派）：

| 派别 | 创始人 | 特点 |
|------|--------|------|
| 遇仙派 | 马钰 | 以性功为主 |
| 南无派 | 谭处端 | 性命双修 |
| 随山派 | 刘处玄 | 清静无为 |
| 龙门派 | 丘处机 | 影响最大，流传最广 |
| 嵛山派 | 王处一 | 重视内丹 |
| 清静派 | 孙不二 | 女丹修炼 |
| 华山派 | 郝大通 | 融合易学 |

> 龙门派是全真道中影响最大的支派，丘处机曾西行面见成吉思汗，使全真道获得极大发展。

### 3. 正一与全真对比

| 项目 | 正一道 | 全真道 |
|------|--------|--------|
| 修行侧重 | 符箓斋醮 | 内丹清修 |
| 道士身份 | 可居家 | 必须出家 |
| 饮食 | 不忌荤腥 | 清素断荤 |
| 婚姻 | 可婚娶 | 不婚娶 |
| 经典侧重 | 三洞符箓 | 道德、清净 |
| 宫观风格 | 活跃于民间 | 清修于山林 |

## 二、道教仪轨概述

### 1. 斋醮

斋醮是道教最重要的仪式体系：

- **斋**：清洁身心，忏悔祈福
- **醮**：设坛祭祀，上章祈请

常见斋醮类型：
- **金箓大斋**：为国祈福
- **黄箓大斋**：度化亡灵
- **玉箓大斋**：为臣修设
- **三官斋**：依三官大帝设斋

### 2. 日常功课

宫观道士每日必行的功课：

- **早课**：清晨诵经，通常诵《清净经》《心印经》等
- **晚课**：傍晚诵经，通常诵《救苦经》《三官经》等
- **朔望日**：初一、十五加诵更多经典

### 3. 主要节日

| 节日 | 日期 | 意义 |
|------|------|------|
| 三清节 | 冬至、夏至、二月十五 | 元始、灵宝、道德天尊圣诞 |
| 玉皇圣诞 | 正月初九 | 玉皇大帝诞辰 |
| 上元节 | 正月十五 | 天官赐福 |
| 中元节 | 七月十五 | 地官赦罪 |
| 下元节 | 十月十五 | 水官解厄 |
| 真武圣诞 | 三月初三 | 真武大帝诞辰 |
| 吕祖圣诞 | 四月十四 | 吕洞宾诞辰 |
| 邱祖圣诞 | 正月十九 | 丘处机诞辰 |

### 4. 戒律

#### 初真戒（初入道者须受）

- 不得违逆父母师长
- 不得杀生害命
- 不得偷盗邪淫
- 不得嗔恨斗讼
- 不得妄言绮语

#### 中极戒

进阶戒律，约束更为严格。

#### 天仙大戒

最高戒律，全真道士受戒之极则。

### 5. 法服与冠巾

- **道袍**：青色（蓝色）为主，取天地之色
- **道巾**：混元巾、庄子巾、一字巾等
- **法服**：斋醮时穿着的专用服饰
- **冠簪**：道士束发所用

> 正一道士与全真道士在法服上有所区别，全真道士蓄发挽髻，正一道士部分不蓄发。
