# 天界神格体系

## 一、至高神

### 道——终极超越

"道"在道教神学中是超越一切神格的终极实在：

> 道生一，一生二，二生三，三生万物。——《道德经》第四十二章

道非人格神，而是宇宙的终极法则与本源，一切神灵皆由道化生。

### 太一——汉代至高神

秦汉时期的至高神，被汉武帝尊为国家最高祭祀对象：

- **全称**：昊天上帝太一
- **地位**：汉代五祀之首
- **祭祀**：甘泉宫太一祠
- **演变**：后世融入玉皇大帝信仰

## 二、三清——道教最高神格

三清是道教神格体系中最高的一层，代表"道"的三个面相：

### 元始天尊

| 项目 | 内容 |
|------|------|
| 全称 | 玉清圣境元始天尊 |
| 所居 | 清微天玉清境 |
| 象征 | 宇宙创生之始（无极→太极） |
| 神诞 | 冬至日 |
| 法相 | 手执黍米之珠（或虚空无一物） |

### 灵宝天尊

| 项目 | 内容 |
|------|------|
| 全称 | 上清真境灵宝天尊 |
| 所居 | 禹余天之上清境 |
| 象征 | 宇宙运行之道（太极→两仪） |
| 神诞 | 夏至日 |
| 法相 | 手执如意（或手捧太极） |

### 道德天尊（太上老君）

| 项目 | 内容 |
|------|------|
| 全称 | 太清仙境道德天尊 |
| 所居 | 大赤天太清境 |
| 象征 | 道德教化之尊（万物体道而行） |
| 神诞 | 二月十五日 |
| 法相 | 手执芭蕉扇（或拂尘） |

> 三清非三神，实为道之一体三面：元始象征道之本体，灵宝象征道之运行，道德象征道之教化。

## 三、四御——执掌天道

四御辅佐三清，实际执掌天地万物的运行：

### 1. 玉皇大帝

- **全称**：昊天金阙无上至尊自然妙有弥罗至高玉皇上帝
- **职能**：总执天道，为万神之主、万天之尊
- **地位**：在三清之下、众神之上，实际管理天界
- **祭祀**：正月初九玉皇圣诞

> 民间常将玉皇大帝视为"天上的皇帝"，是最高神。但在道教神学中，其位在三清之下。

### 2. 紫微北极大帝

- **全称**：中天紫微北极大帝
- **职能**：执掌天经地纬、统御万星、节制四时
- **来历**：源于北极星的星辰崇拜

### 3. 勾陈上宫天皇大帝

- **全称**：勾陈上宫天皇大帝
- **职能**：执掌天地人三才，统御万雷，主持兵戈

### 4. 后土皇地祇

- **全称**：承天效法厚德光大后土皇地祇
- **职能**：执掌阴阳生育、大地山河、万物之美
- **地位**：与玉皇对应，为"天公地母"中的地母

## 四、五方五老——五方之帝

五方五老是五方天区的至高神，源自上古五方帝神话：

| 方位 | 尊号 | 对应色 | 对应帝 |
|------|------|--------|--------|
| 东方 | 青灵始老苍帝君 | 青 | 太皞 |
| 南方 | 丹灵真老赤帝君 | 赤 | 炎帝 |
| 中央 | 元灵元老黄帝君 | 黄 | 黄帝 |
| 西方 | 皓灵皇老白帝君 | 白 | 少皞 |
| 北方 | 五灵玄老黑帝君 | 黑 | 颛顼 |

## 五、日月星辰之神

### 日月

- **日神**：羲和（御日之神）/ 太阳星君
- **月神**：常羲（御月之神）/ 太阴星君
- **关系**：日为阳之宗，月为阴之宗

### 斗姆与星君

- **斗姆元君**：众星之母，北斗九星之母
- **南斗六星君**：主生（延寿度人）
- **北斗七星君**：主死（解厄消灾）

> "南斗注生，北斗注死"——南斗管生籍，北斗管死籍。

### 太岁星君

- 六十甲子各有值年太岁
- 民间信仰中，冲犯太岁需禳解
- 太岁星君掌管当年吉凶

## 六、三官大帝

三官大帝源自早期天师道的三官手书信仰：

| 大帝 | 全称 | 职能 | 诞辰 | 对应节日 |
|------|------|------|------|----------|
| 天官 | 上元一品赐福天官紫微大帝 | 赐福 | 正月十五 | 上元节 |
| 地官 | 中元二品赦罪地官清虚大帝 | 赦罪 | 七月十五 | 中元节 |
| 水官 | 下元三品解厄水官洞阴大帝 | 解厄 | 十月十五 | 下元节 |

> 三官信仰是道教最古老的神格之一，天师道早期以三官手书代替符箓。

## 七、雷部诸神

- **九天应元雷声普化天尊**：雷部之主
- **雷公电母**：行雷施电
- **风伯雨师**：兴风降雨
- **五雷正法**：道教雷法体系

雷部在道教法术中地位重要，许多道法以役使雷部为功。
