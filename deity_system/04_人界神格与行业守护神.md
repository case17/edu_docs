# 人界神格与行业守护神

## 一、人神转化机制

中国神格体系最独特的机制是**人可成神**，这是中国有别于其他文明神格体系的核心特征。

### 人神转化的条件

| 条件 | 说明 | 典型 |
|------|------|------|
| 忠义 | 为国尽忠、以义著称 | 关羽、岳飞 |
| 孝悌 | 孝顺父母、友爱兄弟 | 闵子骞、曾参 |
| 功业 | 治国安民、除害兴利 | 大禹、李冰 |
| 灵异 | 死后显灵、有求必应 | 妈祖、陈靖姑 |
| 技艺 | 发明创造、造福百工 | 仓颉、鲁班 |

### 封神的路径

```
历史人物 → 民间奉祀 → 地方神灵 → 朝廷敕封 → 全国性神灵
```

以关羽为例：
1. 三国：关羽殉国
2. 南朝：民间开始奉祀
3. 唐代：佛教封为伽蓝护法
4. 宋代：朝廷封"义勇武安王"
5. 明代：封"三界伏魔大帝神威远镇天尊关圣帝君"
6. 清代：与孔子并列，"武圣"

## 二、忠义英烈神

### 关圣帝君（关羽）

| 项目 | 内容 |
|------|------|
| 本名 | 关羽，字云长 |
| 时代 | 东汉末年 |
| 神格 | 武圣、关圣帝君、伏魔大帝 |
| 职能 | 忠义之神、武神、财神（武财神） |
| 三教共尊 | 儒称武圣，释称伽蓝，道称伏魔大帝 |

> 关羽是三教共尊、朝野共奉的典型，其神格攀升之高、涵盖之广，在中国诸神中首屈一指。

### 岳飞

- **尊号**：岳武穆王、鄂王
- **职能**：忠烈之神、护国武神
- **地位**：与关羽并列的武神
- **争议**：部分地区关岳合祀，部分地区因满清忌讳而以岳飞为主神

### 其他忠义神

| 神灵 | 时代 | 主要神职 |
|------|------|----------|
| 诸葛亮 | 三国 | 智慧之神 |
| 文天祥 | 南宋 | 忠烈之神 |
| 戚继光 | 明代 | 海防武神 |

## 三、地方守护女神

### 妈祖（林默娘）

| 项目 | 内容 |
|------|------|
| 本名 | 林默娘 |
| 时代 | 北宋 |
| 神格 | 天妃→天后→天上圣母 |
| 职能 | 护航、救难、护渔 |
| 传播 | 福建→台湾→东南亚→全球华人 |

妈祖信仰的层级攀升：
- 宋封"灵惠夫人"→"灵惠妃"
- 元封"天妃"
- 清封"天后"
- 今为联合国非遗项目

### 碧霞元君

- **全称**：天仙玉女碧霞护世弘济真人
- **道场**：泰山碧霞祠
- **职能**：送子、护幼、疗疾
- **别称**：泰山老奶奶、泰山娘娘
- **信众**：北方民间，尤以妇女信奉最虔

### 陈靖姑（临水夫人）

- **时代**：唐代
- **职能**：扶胎救产、保赤佑童
- **地域**：福建、台湾
- **与妈祖**：妈祖护海，陈靖姑护产，并称"二奶"

## 五、家宅六神

中国传统家宅中供奉的六位守护神：

| 序位 | 神灵 | 位处 | 职能 |
|------|------|------|------|
| 1 | 门神 | 大门 | 挡邪护宅 |
| 2 | 户牖神 | 窗户 | 守护通风采光 |
| 3 | 井神 | 水井 | 司井泉清水 |
| 4 | 灶神 | 灶台 | 司命监察，上天言事 |
| 5 | 中霤神 | 屋中 | 守护家宅中心 |
| 6 | 行神 | 出行 | 保佑出行平安 |

> 五祀（门、户、井、灶、中霤）之制载于《礼记》，是中国最古老的家宅守护神体系。

## 六、行业守护神的文化意义

1. **技艺传承的象征**：守护神代表行业起源与传承
2. **职业认同的标志**：同业者共祀一神，强化行业认同
3. **技艺伦理的约束**：守护神的品格是行业道德标杆
4. **民间智慧的保存**：守护神传说中保存行业知识与诀窍
