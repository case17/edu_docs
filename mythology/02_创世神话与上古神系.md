# 创世神话与上古神系

## 一、盘古开天辟地

### 原始记载

> 天地混沌如鸡子，盘古生其中。万八千岁，天地开辟，阳清为天，阴浊为地。盘古在其中，一日九变，神于天，圣于地。——《三五历纪》

### 开辟过程

1. **混沌**：天地未分，如鸡子（鸡蛋）一般
2. **开辟**：盘古以神力劈开天地，阳清上升为天，阴浊下沉为地
3. **撑持**：天日高一丈，地日厚一丈，盘古日长一丈，如此万八千岁
4. **化生**：盘古身死，化为万物

### 盘古化生万物

| 盘古之身 | 化为 |
|----------|------|
| 左眼 | 日 |
| 右眼 | 月 |
| 头发 | 星辰 |
| 血液 | 江河 |
| 肌肉 | 田土 |
| 皮肤 | 草木 |
| 齿骨 | 金石 |
| 汗液 | 雨泽 |
| 呼吸 | 风云 |
| 声音 | 雷霆 |
| 四肢 | 四极 |
| 躯干 | 五岳 |

### 文化意义

- 中国最完整的创世神话
- 体现"身化万物"的宇宙观——人与自然同源同体
- 隐含牺牲创世的精神内核

## 二、女娲创世

### 1. 女娲造人

> 俗说天地开辟，未有人民，女娲抟黄土作人。剧务，力不暇供，乃引绳縆于泥中，举以为人。——《风俗通义》

两种造人方式：
- **抟黄土**：精心捏制，化为富贵之人
- **引绳泥中**：甩泥成点，化为贫贱之人

> 此说法反映了古代等级观念，但女娲作为人类之母的地位不变。

### 2. 女娲补天

> 往古之时，四极废，九州裂，天不兼覆，地不周载……于是女娲炼五色石以补苍天，断鳖足以立四极，杀黑龙以济冀州，积芦灰以止淫水。——《淮南子》

灾变原因：共工怒触不周山，天柱折，地维缺

补天过程：
1. 炼五色石补天
2. 断鳖足立四极
3. 杀黑龙止水患
4. 积芦灰止淫水

## 三、上古五方天帝体系

中国上古神话形成了一套五方天帝的神系：

| 方位 | 天帝 | 佐神 | 色 | 时令 |
|------|------|------|----|------|
| 中央 | 黄帝 | 后土 | 黄 | 季夏 |
| 东方 | 太皞 | 句芒 | 青 | 春 |
| 南方 | 炎帝 | 祝融 | 赤 | 夏 |
| 西方 | 少皞 | 蓐收 | 白 | 秋 |
| 北方 | 颛顼 | 玄冥 | 黑 | 冬 |

### 黄帝——中央天帝

- 号轩辕氏、有熊氏
- 统一华夏，涿鹿之战击败蚩尤
- 发明舟车、弓矢、衣裳、历法
- 后被道教尊为神，被史家尊为人文初祖

### 炎帝——南方天帝

- 号神农氏、烈山氏
- 教民耕种，尝百草知药性
- 与黄帝战于阪泉，败后两族融合（华夏族来源）

### 颛顼——北方天帝

- 号高阳氏
- 绝地天通——命重、黎切断天地通道
- 确立人神分界，人界秩序由此确立

## 四、三皇五帝

三皇五帝是中国神话历史化后的上古帝王体系，诸说不一：

### 常见三皇说

1. 伏羲、女娲、神农
2. 燧人、伏羲、神农
3. 天皇、地皇、人皇

### 常见五帝说

1. 黄帝、颛顼、帝喾、尧、舜
2. 太皞、炎帝、黄帝、少皞、颛顼

### 各帝功业

| 帝号 | 主要功业 |
|------|----------|
| 伏羲 | 画八卦，制嫁娶，造网罟 |
| 女娲 | 造人，补天，制笙簧 |
| 神农 | 教耕稼，尝百草，制琴瑟 |
| 燧人 | 钻木取火 |
| 黄帝 | 统一华夏，制器用，创文字 |
| 颛顼 | 绝地天通，制历法 |
| 帝喾 | 设官分职，制节气 |
| 尧 | 禅让帝位，设谏鼓谤木 |
| 舜 | 孝悌感天，命禹治水 |

## 五、创世神话的哲学意蕴

1. **从无到有**：混沌开辟，反映宇宙起源的朴素理解
2. **身化万物**：盘古化生，体现人与自然一体
3. **阴阳化生**：清浊分判，奠定阴阳思想基础
4. **循环创世**：毁而再造（补天），体现宇宙循环观
5. **道德创世**：造人补天皆为苍生，神以德立
