# 山海经神话

## 一、《山海经》简介

《山海经》是中国最重要的神话文献，约成书于战国至汉初，保留了大量上古神话的原始面貌。

### 基本信息

- **篇数**：十八卷（山经五卷、海经八卷、大荒经四卷、海内经一卷）
- **内容**：山川地理、物产矿藏、异方国度、神灵异兽、神话传说
- **性质**：巫书、地理书、神话宝库

> 鲁迅称之为"古之巫书"，袁珂誉其为"神话之渊府"。

## 二、《山海经》中的主要神话

### 1. 夸父逐日

> 夸父与日逐走，入日；渴，欲得饮，饮于河、渭；河、渭不足，北饮大泽。未至，道渴而死。弃其杖，化为邓林。——《海外北经》

**解读**：
- 夸父立志追赶太阳，象征先民征服自然的雄心
- 虽死犹化邓林（桃林），体现精神不朽
- 与希腊伊卡洛斯神话对比：同样挑战极限，夸父更具悲壮崇高

### 2. 精卫填海

> 炎帝之少女名曰女娃。女娃游于东海，溺而不返，故为精卫。常衔西山之木石，以堙于东海。——《北山经》

**解读**：
- 女娃溺亡化为精卫鸟，衔木石填海不止
- 象征不屈不挠、矢志不渝的精神
- 以弱小对抗强大，以有限挑战无限

### 3. 刑天舞干戚

> 刑天与帝争神，帝断其首，葬之常羊之山。乃以乳为目，以脐为口，操干戚以舞。——《海外西经》

**解读**：
- 刑天被斩首仍持盾斧战斗
- 陶渊明赞曰："刑天舞干戚，猛志固常在"
- 不屈意志的最高象征

### 4. 鲧禹治水

**鲧**：
> 洪水滔天，鲧窃帝之息壤以堙洪水，不待帝命。帝令祝融杀鲧于羽郊。——《海内经》

**禹**：
> 禹鲧是始布土，均定九州。——《海内经》

对比：
- 鲧用堵法（堙），失败被杀
- 禹用疏法（导），成功治水
- 父子相继，体现方法传承与创新

### 5. 黄帝战蚩尤

> 蚩尤作兵伐黄帝，黄帝乃令应龙攻之冀州之野。应龙蓄水，蚩尤请风伯雨师，纵大风雨。黄帝乃下天女曰魃，雨止，遂杀蚩尤。——《大荒北经》

战争过程：
1. 蚩尤作兵伐黄帝
2. 应龙蓄水攻蚩尤
3. 蚩尤请风伯雨师纵风雨
4. 黄帝召女魃止雨
5. 蚩尤败，被杀于冀州之野

## 三、山海异兽

《山海经》记载了大量奇异生物，大致可分为：

### 祥瑞之兽

| 名称 | 形态 | 寓意 |
|------|------|------|
| 凤凰 | 鸡首燕颔蛇颈龟背 | 天下太平 |
| 麒麟 | 鹿身牛尾马蹄 | 祥瑞之征 |
| 白泽 | 狮身人面 | 知天下鬼神事 |
| 鸾鸟 | 如凤而小 | 太平之应 |

### 凶兆之兽

| 名称 | 形态 | 出现则 |
|------|------|--------|
| 穷奇 | 如牛猬毛音如獆狗 | 大风 |
| 饕餮 | 羊身人面虎齿 | 贪暴 |
| 梼杌 | 如虎人面犬毛 | 顽凶 |
| 混沌 | 如犬长毛无目 | 是非颠倒 |

### 四凶

> 四凶为穷奇、饕餮、梼杌、混沌，传说为舜所流放的四族凶恶始祖。

### 四灵

> 麟、凤、龟、龙，谓之四灵。——《礼记》

## 四、海外诸国

《山海经》记载了众多奇异国度：

| 国名 | 特征 |
|------|------|
| 结匈国 | 人皆结胸 |
| 交胫国 | 人两脚交曲 |
| 长臂国 | 手臂极长 |
| 一目国 | 人只有一目 |
| 三身国 | 人一首三身 |
| 无肠国 | 人无肠 |
| 羽民国 | 人有翼能飞 |
| 不死国 | 人皆长寿不死 |
| 奇肱国 | 人一臂三目，善造飞车 |

> 这些异国记载，可能源于对远方民族的想象与传闻，也可能带有巫术色彩。

## 五、《山海经》的学术价值

1. **神话学**：中国上古神话最重要的保存者
2. **民俗学**：反映上古巫术信仰与民俗
3. **地理学**：记载古代山川物产
4. **民族学**：保存远古部族信息
5. **博物学**：记录古代动植物矿物知识
